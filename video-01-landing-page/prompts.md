# Video 01 — Building a Professional Business Website with OpenAI Codex

**YouTube:** https://www.youtube.com/@IHBusinessOnline

**Project:** LUM. Photography

**Tech stack:** Next.js, TypeScript, Tailwind CSS

This file contains the prompts used to build and refine a premium photography website with OpenAI Codex.

## Prompt 1 — Build the Website

```text
We are building a website for a fictional photography business called LUM. Photography.

Business:
Premium wedding and couples photographer based in California, USA.

Target customers:
Couples looking for natural, emotional and timeless photography.

This first milestone is ONLY the public marketing website.

Do not add:
- authentication
- database
- CMS
- payments
- AI features
- booking system

Tech:
- Next.js
- TypeScript
- Tailwind CSS

Build a polished, responsive photography website.

Required sections:
1. Navigation
2. Hero
3. Selected portfolio
4. About the photographer
5. Photography services
6. Testimonials
7. FAQ
8. Contact CTA
9. Footer

Design direction:
- editorial
- premium
- minimal
- photography-first
- generous whitespace
- strong typography
- subtle interactions
- avoid generic SaaS design
- avoid excessive gradients
- fully responsive
- accessible

The photography should be the visual focus.

Before writing code:
1. Inspect the current repository.
2. Propose a short page structure.
3. Explain the visual direction.
4. Then implement it.
5. Run the project.
6. Check for errors and fix them.

Do not add functionality outside this milestone.
```

## Prompt 2 — Improve the Design

```text
Stop adding features.

Review this website as an experienced creative director specializing in premium photography brands.

Identify the 5 things that make the current design feel generic or template-like.

Focus on:
- typography
- image composition
- spacing
- hierarchy
- storytelling
- emotional impact

Then improve those five areas without adding new functionality.

The final website should feel designed for a real premium photographer, not generated from a generic website template.
```

## Notes

This project is a fictional photography business created for educational purposes.

The prompts are intended to be adapted to your own project. Results may vary depending on your existing codebase and the AI model used.
